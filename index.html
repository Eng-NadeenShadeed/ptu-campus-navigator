    يطبّق الوكيل اختبار الهدف عند فحص العقدة. المسافات تقديرية مقروءة من الخريطة. عمود «الأقصر؟» يقارن بمرجع Dijkstra للتحقق فقط. BFS يقلّل عدد الخطوات لا الأمتار، لذلك قد لا يجد أقصر مسار عندما تختلف أطوال الطرق. IDS يعدّ الزيارات المتكررة بين التكرارات.The goal test is applied when a node is expanded. Distances are estimates read from the map. “Cheapest?” compares against a Dijkstra reference used only for checking. BFS minimises the number of moves, not metres, so it can miss the cheapest route when road lengths differ. IDS counts repeated visits across its iterations.
